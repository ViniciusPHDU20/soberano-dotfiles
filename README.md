# Soberano Wallpaper Picker (Rust + GTK4 Layer-Shell)

High-performance animated wallpaper vault selector tailored for Hyprland & Wayle Desktop.
- Native Rust + GTK4 + gtk4-layer-shell
- Material Design 3 adaptive theming via Matugen
- Asynchronous thumbnail generation and caching
- Smooth keyboard navigation, search, and category chips

## Build & Install
```bash
cargo build --release
cp target/release/wallpaper-picker-rs ~/.local/bin/
```
